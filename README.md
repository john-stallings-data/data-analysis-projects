# Data Analysis Projects

A collection of data analysis projects demonstrating skills in Python and SQL 
for exploratory data analysis, data cleaning, and business insight generation.

---

## 🛠️ Technologies Used
- **Python** — Data exploration and analysis
- **SQL** — Database querying and aggregation
- **GitHub** — Version control and project management

---

## 📁 Projects

### 1. Data Exploration Template (Python)
**File:** `data_exploration.py`  
**Description:** A reusable Python template for loading and summarising 
CSV datasets. Designed as a starting point for any new data analysis project.

**Key features:**
- CSV file loading and parsing
- Automated dataset summary (row count, column names)
- Clean, reusable function structure

---

### 2. Sales Data Exploration (SQL)
**File:** `sales_exploration.sql`  
**Description:** SQL queries for exploring and summarising sales transaction data.

**Key features:**
- Basic data profiling and record counts
- Sales aggregation by category
- Top 10 product performance ranking
- Monthly sales trend analysis

---

## 🚀 How to Use

### Python Scripts
1. Clone this repository to your local machine
2. Ensure Python is installed
3. Run scripts from the command line:
```
python data_exploration.py
```

### SQL Scripts
1. Open your preferred SQL client
2. Connect to your database
3. Copy and run queries from the relevant `.sql` file
